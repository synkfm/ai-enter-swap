# Claude Enter Swap

Claude を使っているときだけ、キーの動きを入れ替える Windows 用の小さなツールです。

| キー | ふだん | このツールを使うと |
|---|---|---|
| Enter | 送信 | **改行** |
| Shift + Enter | 改行 | **送信** |

長い文章を書いている途中で、うっかり Enter を押して送ってしまう……を防げます。
日本語の変換中に Enter を押したときは、これまでどおり「確定」になります。

- 対象：**Claude デスクトップアプリ**、ブラウザで開いた **claude.ai**（Chrome / Edge / Firefox / Brave / Vivaldi / Opera）
- それ以外のアプリ（メール、Word、LINE など）では、いつもどおりの動きのままです。
- 動作環境：Windows 10 / 11（64ビット）
- 日本語入力：Microsoft IME（Windows標準）、Google日本語入力

> このツールは個人が作った非公式のツールです。Anthropic 社（Claude の提供元）とは関係ありません。

## 使い始めかた

1. ダウンロードした zip ファイルを右クリック →「**すべて展開**」で取り出します。
   （zip の中から直接起動すると、自動起動がうまく動きません）
2. 取り出したフォルダを、消さない場所（例：「ドキュメント」の中）に置きます。
3. `ClaudeEnterSwap.exe` をダブルクリックして起動します。
   - 青い「Windows によって PC が保護されました」という画面が出たら、下の「[警告が出たとき](#警告が出たとき)」を見てください。
4. 初回だけ、「普段使っている日本語入力はどれですか？」と聞かれます。使っているものを選んでください。
   - 何を使っているかわからないときは「Microsoft IME（Windows標準）」を選べば、たいてい大丈夫です。
5. 「変更しました」と出たら準備完了です。
   - **Microsoft IME を選んだ場合は、Claude を開き直してください**（次の章）。

起動すると、画面右下（タスクトレイ）にアイコンが出ます。見えないときは、右下の「**^**」を押すと出てきます。

### Windows の起動時に自動で動かしたいとき

タスクトレイのアイコンを右クリック →「**Windows起動時に自動で起動する**」を押します（チェックが付けばオン）。

## Microsoft IME を使っている人へ（大事）

### 「以前のバージョン」に切り替わります

変換中の Enter で正しく「確定」させるために、キーの設定を1か所だけ変える必要があります。
ところが、Windows 11 の新しい Microsoft IME はその設定を変えられないため、このツールは
**「以前のバージョンの Microsoft IME」に切り替えます**（Windows に最初から入っている、少し前の版です）。

- 入力の仕方はほとんど同じです。変換候補の見た目などが少し変わります。
- 変えるのは「以前のバージョンを使う」「キー設定」の2つだけです。辞書・学習内容・入力モードの表示など、ほかの設定には触りません。
- 元に戻したくなったら、いつでも戻せます（下の「[元に戻すには](#元に戻すには)」）。

### 反映するには、Claude を「完全に終了」して開き直す

Microsoft IME の変更は、アプリを開き直すまで反映されません。
Claude デスクトップアプリは、右上の「×」で閉じても**裏で動き続けています**。次の手順で完全に終了してください。

1. 画面右下（タスクトレイ）の **Claude のアイコン**を右クリック
2. 「**終了**（Quit）」を押す
3. もう一度 Claude を開く

ブラウザで使っている場合は、ブラウザをいったん全部閉じて開き直してください。
それでも変わらないときは、PC を再起動してください。

## Google日本語入力を使っている人へ

Google日本語入力の「キー設定」の中の、**変換中の Shift+Enter を「確定」にする**設定だけを変えます。
アプリを開き直さなくても、すぐに反映されます。

### キー設定が「ATOK」「ことえり」スタイルの人

この2つのスタイルは、自動では変更できません（変更できなかったと表示されます）。次のどちらかで使えます。

- **A. 「MS-IME」スタイルにしてよい場合**
  1. Google日本語入力のプロパティを開く
  2. 「キー設定の選択」を「**MS-IME**」にして「OK」
  3. このツールのアイコンを右クリック →「日本語入力（IME）の設定を調整する」
- **B. 今のスタイルのまま使いたい場合**
  1. Google日本語入力のプロパティ →「キー設定の選択」の横の「**編集**」
  2. モードが「変換前入力中」「変換中」と、名前に「サジェスト」「予測」が付くものについて、入力キー「**Shift Enter**」のコマンドを「**確定**」にする（行が無ければ「編集」→「エントリーを追加」で足す）
  3. 「OK」で閉じる

## タスクトレイのメニュー

アイコンを右クリックすると、次のことができます。

| メニュー | できること |
|---|---|
| 有効 | チェックを外すと一時停止（いつもの Enter に戻ります） |
| 日本語入力（IME）の設定を調整する | 初回の設定をやり直す |
| 日本語入力（IME）の設定を元に戻す | このツールで変えた IME の設定を、変更前に戻す |
| Windows起動時に自動で起動する | 自動起動のオン／オフ |
| 使い方 | 使い方とバージョンを表示 |
| 終了 | ツールを終了 |

## 元に戻すには

### IME の設定だけ戻す

アイコンを右クリック →「**日本語入力（IME）の設定を元に戻す**」→「はい」。
Microsoft IME の場合は、そのあと Claude などのアプリを開き直してください（上の手順で完全に終了してから）。

### ツールを完全にやめる（アンインストール）

1. アイコンを右クリック →「日本語入力（IME）の設定を元に戻す」
2. 「Windows起動時に自動で起動する」にチェックが付いていたら、押して外す
3. 「終了」
4. `ClaudeEnterSwap.exe` のフォルダを削除
5. （任意）エクスプローラーのアドレス欄に `%APPDATA%\ClaudeEnterSwap` と入力して開き、そのフォルダも削除（設定とバックアップが入っています）

> 注意：手順1の前に4・5を行うと、IME を元に戻すためのバックアップも消えてしまいます。必ず1から順番に行ってください。

## 警告が出たとき

このツールには「電子署名」（作った人を証明するしるし）が付いていないため、Windows やウイルス対策ソフトが警告を出すことがあります。

### 「Windows によって PC が保護されました」と出たとき

1. 画面の「**詳細情報**」を押す
2. 「アプリ：ClaudeEnterSwap.exe」と表示されていることを確認
3. 「**実行**」を押す

### ウイルス対策ソフトに止められたとき

このツールは「AutoHotkey」という仕組みで作っています。キー入力を入れ替える仕組みのため、
ウイルス対策ソフトが誤って危ないものと判断することがあります（誤検知）。

- 配布ページに載っている **SHA-256**（ファイルの指紋のようなもの）と、手元のファイルが一致するか確かめると安心です。
  確かめ方：エクスプローラーでフォルダを開き、アドレス欄に `powershell` と入力して Enter → 次を入力して Enter
  ```
  Get-FileHash .\ClaudeEnterSwap.exe
  ```
- 一致していて、それでも不安な場合は、使わないでください。無理に許可する必要はありません。

## このツールがしていること・していないこと

- **していること**
  - Claude の画面が前にあるときだけ、Enter と Shift+Enter を入れ替える
  - 日本語入力（IME）のキー設定を1か所変える（変更前のバックアップを `%APPDATA%\ClaudeEnterSwap` に保存）
  - Microsoft IME の場合は「以前のバージョン」に切り替える
- **していないこと**
  - 入力した文字を記録・保存・送信すること（インターネットには一切つながりません）
  - Claude 以外のアプリでの動きを変えること

## よくある質問

**Q. 変換中に Enter を押したら、確定と同時に改行されてしまう**
A. IME の設定がまだ反映されていません。Microsoft IME の場合は、Claude を完全に終了して開き直してください。
Google日本語入力の場合は、メニューの「日本語入力（IME）の設定を調整する」をもう一度試してください。

**Q. 急に Enter で送信されるようになった**
A. ツールが終了している可能性があります。タスクトレイにアイコンがあるか確認し、無ければもう一度起動してください。

**Q. 一時的にふだんの Enter に戻したい**
A. アイコンを右クリック →「有効」のチェックを外します。
